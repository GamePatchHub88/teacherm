# TeacherM — منصة المدرسين لنشر نتائج الطلاب

[![Repo](https://img.shields.io/badge/GitHub-GamePatchHub88%2Fteacherm-0f766e?logo=github)](https://github.com/GamePatchHub88/teacherm)

منصة عربية تتيح لكل مدرس نشر نتائج طلابه برابط واحد خاص به (`/t/اسم-المدرس`).
الطالب يكتب اسمه أو رقم جلوسه فتظهر نتيجته فوراً من الموبايل، ويستطيع مشاركتها أو تحميلها كصورة.

## المميزات

- **رفع من Excel / CSV** أو إضافة الطلاب يدوياً (تعديل وحذف في أي وقت).
- **مجموعات الطلاب** (فصل / سنتر / دفعة): أضف الطلاب مرة واحدة ثم أنشئ لهم أي امتحان.
- **بحث بالاسم ورقم الجلوس** مع تجاهل التشكيل والهمزات.
- **ثيم خاص بكل مادة** — ليس ألواناً فقط، بل أيضاً رموز وزخارف وأشكال وخطوط:

  | المادة | الهوية البصرية |
  |---|---|
  | اللغة العربية | حروف عائمة، إطار مزدوج كالمخطوطات، خط أميري، فاصل ❖ |
  | الرياضيات | رموز ∑ π √ ∞، خلفية ورقة رسم بياني، محاور، أرقام بخط أحادي المسافة |
  | اللغة الإنجليزية | حروف A Z & وعلامات اقتباس، دفتر مسطّر، فقاعات حوار |
  | العلوم | ⚛ H₂O Δ λ، مدارات، خلفية نقطية، أيقونات سداسية |
  | الدراسات الاجتماعية | ◎ ✦ ⌖، خطوط الطول ودبابيس الخرائط، أيقونات دائرية |
  | المواد الشرعية | ☪ ۞ ﴾ ﴿، واجهة على شكل محراب، أيقونات ثمانية، خط أميري |

- **باقات اشتراك** (امتحان واحد / شهر / سنة / مدى الحياة): بطاقات بأيقونة وسعر واضح، ونسبة توفير تلقائية للسنة،
  وتمييز باقة المدرس الحالية، والاشتراك عبر واتساب.
- **لوحة إدارة** للمدير: المدرسون، الباقات والأسعار، ألوان المنصة، الدخول لحساب أي مدرس للدعم.
- وضع فاتح وداكن، وتصميم متجاوب للموبايل.

## التشغيل محلياً

```bash
git clone https://github.com/GamePatchHub88/teacherm.git
cd teacherm
npm install
cp .env.example .env   # أو أنشئ ملف .env يدوياً بالمتغيرات أدناه
npm start              # http://localhost:3000
```

### متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `MONGODB_URI` | رابط قاعدة بيانات MongoDB (مثال: Atlas) |
| `JWT_SECRET` | نص سري طويل وعشوائي لتوقيع الجلسات — **غيّره دائماً** |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | بيانات حساب المدير، يُنشأ تلقائياً عند أول تشغيل |
| `AUTO_APPROVE` | `false` ليراجع المدير كل مدرس جديد قبل تفعيله (الافتراضي: تفعيل تلقائي) |
| `NODE_ENV` | `production` على الاستضافة (يفعّل `secure` للكوكيز) |

## الصفحات

| المسار | من يدخله |
|---|---|
| `/` | الجميع — الصفحة الرئيسية والباقات |
| `/login` | الجميع — دخول وتسجيل حساب جديد |
| `/t/اسم-المدرس` | الطلاب — صفحة النتائج العامة |
| `/dashboard` | **المدرس فقط** — إدارة امتحاناته وطلابه وموقعه |
| `/admin` | **المدير فقط** — إدارة المنصة |

## الأمان

- صفحتا `/admin` و `/dashboard` موجودتان في مجلد `views/` (خارج `public/`) ولا تُخدمان إلا بعد التحقق من الجلسة
  والدور **على الخادم**: الزائر يُحوَّل إلى `/login`، والمدرس الذي يحاول فتح `/admin` يُحوَّل إلى `/dashboard`،
  والمدير يُحوَّل من `/dashboard` إلى `/admin`.
- زر لوحة المدرس لا يظهر في صفحة الطلاب العامة إلا لصاحب الصفحة نفسه بعد تسجيل دخوله.
- كل مسارات `/api/admin/*` محمية بصلاحية المدير في الخادم.
- جلسة "الدخول لحساب مدرس" (impersonation) تحمل ادعاءً خاصاً `adm`، فلا يمكن لمدرس إعادة استخدام كوكي جلسته العادية بدلاً منها.
- كلمات المرور مشفّرة بـ bcrypt، والكوكيز `httpOnly`، وهناك حدّ لمحاولات الدخول والبحث.

## النشر

**أي استضافة Node** (Render / Railway / VPS): `npm start` مع ضبط المتغيرات أعلاه.

**Vercel:**
1. أضف المتغيرات في *Settings → Environment Variables*.
2. في MongoDB Atlas: *Network Access → Allow 0.0.0.0/0*.
3. ملف `vercel.json` يوجّه `/admin` و `/dashboard` و `/api/*` إلى الخادم، ويضمّن مجلد `views/` مع الدالة.

## هيكل المشروع

```
├── api/index.js        نقطة دخول Vercel
├── server.js           الخادم وواجهات API وحماية الصفحات
├── vercel.json         إعادة التوجيه وتضمين views
├── public/             ملفات عامة (الرئيسية، الدخول، صفحة الطلاب، app.js، style.css)
└── views/              صفحات محمية (admin.html, dashboard.html)
```

## ملاحظة عند الترقية من نسخة قديمة

احذف `public/admin.html` و `public/dashboard.html` القديمين بعد إضافة مجلد `views/`، وإلا بقيت نسخة عامة منهما.
